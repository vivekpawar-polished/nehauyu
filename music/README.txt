DROP YOUR MUSIC FILE HERE
=========================
Supported formats: .mp3  .ogg  .m4a  .aac

How to add music:
  1. Copy your song file into this folder, e.g. "love-song.mp3"
  2. Open js/config.js and set:
       musicSrc: "music/love-song.mp3"

Tips:
  - Keep the file under 5 MB for fast mobile loading.
  - The song loops automatically and never autoplays — it starts on the
    first tap/click by the guest.
  - If musicSrc is left empty (""), the built-in Web Audio melody plays instead.
